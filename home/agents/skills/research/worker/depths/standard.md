# Standard Research Depth

The research depth provides approximate guardrails, not quotas. 

Exceed them when the question requires; stop earlier only when the question is narrow and additional research has clearly stopped producing useful evidence.

## Searches

For a `standard` research depth, ~3-5 successful focused searches should be used to effectively discover: multiple, independent, & high-quality sources for each key question.

## Fetches

For a `standard` research depth, ~5-8 high-quality sources should be fetched to answer each key question.
