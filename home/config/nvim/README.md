# Neovim

I use [lazy.nvim][] as my Neovim package manager. The [lazy.lua][] file handles both the installation and configuration
of lazy. This allows for a relatively simple setup process, see: [requirements][#requirements] for more.

## Requirements

* Neovim v0.12.0 (or later).
* The `tree-sitter-cli` installed and on the OS' $PATH.

[lazy.lua]: ./lua/config/lazy.lua
[lazy.nvim]: https://github.com/folke/lazy.nvim
[Tree-sitter]: https://tree-sitter.github.io/tree-sitter/
